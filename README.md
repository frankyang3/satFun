# IO Game

This is a simple online multiplayer game built with Node.js, React, and socket.io.

## How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   ```
2. **Install dependencies:**
   - **Server:**
     ```bash
     npm install
     ```
   - **Client:**
     ```bash
     npm install --prefix client
     ```
3. **Run the server:**
   ```bash
   node server/index.js
   ```
4. **Run the client:**
   ```bash
   npm start --prefix client
   ```

The client will be running on `http://localhost:3000` and the server on `http://localhost:3001`. Open multiple browser tabs to see the multiplayer functionality.
